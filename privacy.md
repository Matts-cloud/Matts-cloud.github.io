# My Clipper — Privacy Policy

*Last updated: 28 September 2026*

## 1. Overview
My Clipper is a personal tool that uploads clips to the operator's own TikTok account. It isn't a public service and doesn't collect data from the public.

## 2. Data we access
When the operator connects their TikTok account, the app receives from TikTok:
- an access token and refresh token, so it can upload videos to that account
- basic profile information (display name), to confirm which account is connected

The app requests only the permissions it needs: `user.info.basic` and `video.publish`.

## 3. How data is used
This data is used only to upload videos the operator has chosen to post, and to confirm the connection works. It isn't used for advertising, profiling or any other purpose.

## 4. Storage and security
Tokens are stored on the operator's private server, readable only by the app's own user account. They aren't shared with, sold to or disclosed to anyone.

## 5. Other people's data
The app doesn't access, collect or store data about any other TikTok users.

## 6. Data removal
The operator can disconnect the app at any time in TikTok's settings (Security > Manage app permissions). Deleting the app's stored tokens removes all data it holds.

## 7. Changes
This policy may be updated. The latest version is always on this page.
